Create `nextjs/components/tour/TourController.tsx` as a client component.

**Imports:**
- `useState`, `useEffect`, `useRef`, `useCallback` from 'react'
- `useTour` from '@/components/providers/TourProvider'
- `TOUR_STEPS` from '@/lib/tour/steps'
- `TourOverlay` from './TourOverlay'
- `TourTooltip` from './TourTooltip'

**State:**
- `targetRect: DOMRect | null` (state, null when target not found)
- `tooltipPosition: { top: number; left: number }` (state)
- `tooltipRef: useRef<HTMLDivElement>(null)` (ref for focus management and position measurement)

**Core logic:**

1. **Read tour context:** `const { isActive, currentStep, stepCount, next, back, skip, complete } = useTour();`
   Get current step config: `const step = TOUR_STEPS[currentStep];`

2. **Position calculation function** `computePosition(targetRect: DOMRect, tooltipEl: HTMLDivElement, placement: TourStep['placement']): { top: number; left: number }`:
   - Gap between target and tooltip: 12px
   - For `bottom`: top = targetRect.bottom + 12, left = targetRect.left + targetRect.width/2 - tooltipEl.offsetWidth/2
   - For `top`: top = targetRect.top - tooltipEl.offsetHeight - 12, left = same centering
   - For `right`: top = targetRect.top + targetRect.height/2 - tooltipEl.offsetHeight/2, left = targetRect.right + 12
   - For `left`: top = same centering, left = targetRect.left - tooltipEl.offsetWidth - 12
   - **Viewport clamping (16px margin from edges per UI-SPEC):**
     ```typescript
     const margin = 16;
     pos.left = Math.max(margin, Math.min(pos.left, window.innerWidth - tooltipEl.offsetWidth - margin));
     pos.top = Math.max(margin, Math.min(pos.top, window.innerHeight - tooltipEl.offsetHeight - margin));
     ```

3. **Target location and positioning useEffect** (deps: `[isActive, currentStep]`):
   - If `!isActive`, return early.
   - Query target: `const targetEl = document.querySelector(step.targetSelector);`
   - If target is null: `console.warn('Tour target not found: ' + step.targetSelector + '. Showing tooltip centered.');` Set `targetRect` to null. Center tooltip: `{ top: window.innerHeight / 2 - 100, left: window.innerWidth / 2 - 170 }`.
   - If target found:
     - **Auto-scroll (per D-07):** Check if target is in viewport. If not: `targetEl.scrollIntoView({ behavior: 'smooth', block: 'center' });` Then wait 300ms before measuring position (use setTimeout with cleanup ref to avoid stale setState).
     - After scroll settles: `const rect = targetEl.getBoundingClientRect();` Set `targetRect` to rect.
     - **aria-describedby on target (per D-14):** `targetEl.setAttribute('aria-describedby', 'tour-tooltip-body');` Cleanup: remove attribute on step change or tour end.
   - After targetRect is set, compute tooltip position using `computePosition` (needs RAF or second useEffect that runs when targetRect changes and tooltipRef.current is available).

4. **Second useEffect for tooltip positioning** (deps: `[targetRect, isActive]`):
   - When targetRect changes and tooltipRef.current exists, call computePosition and set tooltipPosition.
   - Use `requestAnimationFrame` to ensure tooltip has rendered before measuring its size.

5. **Resize handler useEffect** (deps: `[isActive, currentStep]`):
   - If `!isActive`, return.
   - Debounced resize listener (100ms) that re-queries target element, updates targetRect, and recomputes position.
   - Cleanup: remove listener.

6. **Keyboard handler useEffect (per D-12, D-13)** (deps: `[isActive, currentStep, next, back, skip, stepCount]`):
   - If `!isActive`, return.
   - `window.addEventListener('keydown', handleKeyDown)` with:
     - `Escape`: call `skip()`, `e.preventDefault()`
     - `ArrowRight`: call `next()` (only if currentStep < stepCount - 1), `e.preventDefault()`
     - `ArrowLeft`: call `back()` (only if currentStep > 0), `e.preventDefault()`
     - `Tab`: Focus trap logic per RESEARCH.md Pattern 4:
       ```typescript
       const focusable = tooltipRef.current?.querySelectorAll<HTMLElement>(
         'button:not([disabled]), [tabindex]:not([tabindex="-1"])'
       );
       if (!focusable?.length) return;
       const first = focusable[0];
       const last = focusable[focusable.length - 1];
       if (e.shiftKey && document.activeElement === first) {
         e.preventDefault(); last.focus();
       } else if (!e.shiftKey && document.activeElement === last) {
         e.preventDefault(); first.focus();
       }
       ```
   - Cleanup: remove listener.

7. **Focus management useEffect** (deps: `[isActive, currentStep]`):
   - When isActive and tooltipRef.current exists, focus the tooltip container: `tooltipRef.current.focus()`. Use requestAnimationFrame to ensure render is complete.

8. **Cleanup useEffect** for aria-describedby: When step changes or tour ends, remove `aria-describedby` from the previous target element. Track previous target selector in a ref.

9. **Render:**
   - If `!isActive`, return null.
   - Return fragment containing `<TourOverlay targetRect={targetRect} />` and `<TourTooltip step={step} currentStep={currentStep} stepCount={stepCount} position={tooltipPosition} placement={step.placement} onNext={next} onBack={back} onSkip={skip} onComplete={complete} tooltipRef={tooltipRef} />`.

10. Default export.

**Do NOT:**
- Use setTimeout without cleanup (Pitfall from RESEARCH.md anti-patterns)
- Forget to remove aria-describedby from previous target on step change
- Skip viewport clamping (Pitfall 1 from RESEARCH.md)
- Read getBoundingClientRect immediately after scrollIntoView without delay (Pitfall 2)
