**Props interface:**
```typescript
interface TourTooltipProps {
  step: TourStep;
  currentStep: number;
  stepCount: number;
  position: { top: number; left: number };
  placement: TourStep['placement'];
  onNext: () => void;
  onBack: () => void;
  onSkip: () => void;
  onComplete: () => void;
  tooltipRef: React.RefObject<HTMLDivElement | null>;
}
```

**Imports:** `createPortal` from 'react-dom', `useState`/`useEffect`/`forwardRef` from 'react', `cn` from '@/lib/utils', `TourStep` from '@/lib/tour/steps'.

**Component structure (per D-01, D-02, D-03, D-08, D-09, D-10, D-11, UI-SPEC):**

1. **Portal mount guard:** Use `useState(false)` for `mounted`, set true in useEffect. Return null if not mounted. Render via `createPortal(..., document.body)`.

2. **Outer container:** `<div>` with `ref={tooltipRef}`, `role="dialog"`, `aria-modal="true"`, `aria-labelledby="tour-tooltip-title"`, `aria-describedby="tour-tooltip-body"`, `tabIndex={-1}` (for programmatic focus). Style: `position: fixed`, `zIndex: 101`, `top: position.top`, `left: position.left`, max-width 340px, min-width 280px. Classes: `rounded-xl shadow-md border border-[var(--vb-card-border)] bg-[var(--vb-card-bg)] dark:bg-[var(--bg-surface)] dark:border-[var(--border)]`. Enter animation: `animate-[scaleIn_0.15s_ease-out]`.

3. **CSS Arrow (per D-01):** A 12x12px div with `position: absolute`, rotated 45 degrees, same background as tooltip. Position varies by `placement`:
   - `bottom`: arrow on top edge, centered horizontally. `top: -6px`, `left: 50%`, `transform: translateX(-50%) rotate(45deg)`. Border-top and border-left match tooltip border.
   - `top`: arrow on bottom edge. `bottom: -6px`, same horizontal centering. Border-bottom and border-right.
   - `left`: arrow on right edge. `right: -6px`, vertically centered. Border-top and border-right.
   - `right`: arrow on left edge. `left: -6px`, vertically centered. Border-bottom and border-left.
   Arrow classes: `w-3 h-3 bg-[var(--vb-card-bg)] dark:bg-[var(--bg-surface)]`.

4. **Content area (padding: 16px):**
   - Title: `<h3 id="tour-tooltip-title" className="text-sm font-semibold text-[var(--vb-text-primary)] dark:text-[var(--text-primary)]">{step.title}</h3>`
   - Body: `<p id="tour-tooltip-body" className="mt-1 text-sm text-[var(--vb-text-secondary)] dark:text-[var(--text-secondary)]">{step.body}</p>`

5. **Navigation bar (per D-08, separated by border):**
   `<div className="flex items-center justify-between px-4 pt-2 pb-3 border-t border-[var(--vb-card-border)] dark:border-[var(--border)]">`

   - **Left: Skip button** (all steps, per D-10): `<button onClick={onSkip} className="text-sm font-semibold text-[var(--vb-text-muted)] hover:underline">Skip tour</button>`

   - **Center: Step dots** (per D-09): Container with `aria-label={`Step ${currentStep + 1} of ${stepCount}`}`, containing `stepCount` dots. Each dot: `<span className={cn('w-2 h-2 rounded-full', i === currentStep ? 'bg-[var(--vb-accent)]' : 'bg-slate-200 dark:bg-[var(--border)]')} />` with `gap-2` between them.

   - **Right: Back + Next/Done buttons** (per D-10, D-11):
     - Back (hidden on step 0): `<button onClick={onBack} className="px-4 py-2 text-sm font-semibold rounded-lg border border-[var(--vb-card-border)] dark:border-[var(--border)] bg-transparent hover:bg-slate-50 dark:hover:bg-zinc-800">Back</button>`
     - Next (steps 0 to stepCount-2): `<button onClick={onNext} className="px-4 py-2 text-sm font-semibold rounded-lg bg-[var(--vb-accent)] hover:bg-[var(--vb-accent-hover)] text-[#1e293b]">Next</button>`
     - Done (last step only, replaces Next): Same style as Next but text "Done" and `onClick={onComplete}`.

6. **Screen reader live region (per D-14):** `<div aria-live="polite" className="sr-only">Tour step {currentStep + 1} of {stepCount}: {step.title}. {step.body}</div>`

7. Default export.

- Use Framer Motion or any animation library (D-02: CSS transitions only)
- Hardcode step content (read from `step` prop which comes from TOUR_STEPS)
- Add keyboard handlers here (those go in TourController, Plan 03)
