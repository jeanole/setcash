## Component Inventory

Three components in `nextjs/components/tour/`:

### TourOverlay

| Property | Value |
|----------|-------|
| Purpose | Full-viewport SVG overlay with spotlight cutout (D-04, D-05, D-06) |
| Rendering | React portal to document.body |
| Z-index | 100 |
| Overlay fill | rgba(0, 0, 0, 0.5) |
| Cutout shape | Rounded rectangle, rx/ry=8, padding=8px around target bounding box |
| Cutout technique | SVG `<mask>`: white rect (full viewport) + black rect (cutout) |
| Click behavior | pointer-events: none on cutout area; overlay click does NOT dismiss (D-06) |
| Position | fixed, inset: 0 |
| Transition | Cutout rect animates position/size on step change (CSS transition on x/y/width/height, 200ms ease) |

### TourTooltip

| Property | Value |
|----------|-------|
| Purpose | Speech-bubble card with arrow, step content, and navigation (D-01, D-02, D-03) |
| Rendering | React portal to document.body |
| Z-index | 101 |
| Position | fixed, computed via getBoundingClientRect + placement |
| Max width | 340px |
| Min width | 280px |
| Padding | 16px |
| Border radius | 12px (rounded-xl, slightly larger than app's rounded-lg to feel tooltip-like) |
| Shadow | var(--vb-shadow-lg) |
| Border | 1px solid var(--vb-card-border) (light) / var(--border) (dark) |
| Arrow | 12x12px rotated-45 div, same background as tooltip, positioned on the edge facing the target |
| Enter animation | opacity 0->1, scale 0.95->1.0, 150ms ease-out (D-02). Uses existing scaleIn keyframe. |
| Exit animation | opacity 1->0, 100ms ease-in |
| Viewport clamping | 16px minimum distance from any viewport edge; flip placement if tooltip would overflow |
| Auto-scroll | scrollIntoView({ behavior: 'smooth', block: 'center' }) before positioning, 300ms delay (D-07) |
| ARIA | role="dialog", aria-modal="true", aria-labelledby for title, aria-describedby for body (D-14) |
| Focus | Tooltip container receives focus on mount and step change; focus trapped within (D-12) |

#### Tooltip Layout (top to bottom)

```
+------------------------------------------+
|  [Title]                          Step N  |
|  [Body text, max 2 lines]                 |
|------------------------------------------|
|  Skip          . . . . . .    Back  Next  |
+------------------------------------------+
         ^  (arrow pointing to target)
```

- Title: 14px semibold, var(--vb-text-primary)
- Step indicator: "N of 6" shown as `aria-label` on dot container for accessibility; visually dots only
- Body: 14px normal, var(--vb-text-secondary), max 2 lines
- Separator: 1px border-top, var(--vb-card-border)
- Nav bar: 8px padding-top above the bar

#### Navigation Buttons (D-08, D-10, D-11)

| Button | Style | When Visible |
|--------|-------|--------------|
| Skip | Text button, var(--vb-text-muted), 14px medium, no border, no bg. Hover: underline | All steps |
| Back | Outline button, 1px border var(--vb-card-border), bg transparent, 14px medium. Hover: bg var(--vb-accent-light) | Steps 2-6 (hidden on step 1) |
| Next | Solid button, bg var(--vb-accent), text #1e293b, 14px medium, rounded-lg. Hover: bg var(--vb-accent-hover) | Steps 1-5 |
| Done | Same style as Next | Step 6 only (replaces Next) |

Button padding: 8px 16px (py-2 px-4). Button border-radius: 8px (rounded-lg).

#### Step Dots (D-09)

- 6 dots, 8px diameter each (w-2 h-2)
- Gap between dots: 6px
- Current step: bg var(--vb-accent), rounded-full
- Other steps: bg #e2e8f0 (light) / var(--border) (dark), rounded-full
- Container centered in nav bar

### TourController

| Property | Value |
|----------|-------|
| Purpose | Orchestrator: reads useTour(), renders TourOverlay + TourTooltip when isActive (D-07) |
| Rendering | Inline in component tree (mounted inside protected layout via TourProvider) |
| Responsibilities | Query target element via TOUR_STEPS[currentStep].targetSelector, compute bounding rect, handle resize/scroll listeners, trigger scrollIntoView, pass computed positions to child components |
| Resize handling | Debounced window resize listener (100ms), recalculates positions |
| Target not found | Show tooltip centered on screen without spotlight overlay; log console.warn |
| Cleanup | Remove all event listeners on unmount |

### Barrel Export

`nextjs/components/tour/index.ts` re-exports TourController as default export.

## Keyboard & Accessibility Contract (D-12, D-13, D-14)

| Key | Action | Condition |
|-----|--------|-----------|
| Escape | Dismiss tour (calls skip()) | Always when tour active |
| ArrowRight | Next step (calls next()) | When tooltip has focus |
| ArrowLeft | Previous step (calls back()) | When tooltip has focus, step > 1 |
| Tab | Cycle focus forward through tooltip buttons | Trapped within tooltip |
| Shift+Tab | Cycle focus backward through tooltip buttons | Trapped within tooltip |

## Animation Contract

| Animation | Property | Duration | Easing | Trigger |
|-----------|----------|----------|--------|---------|
| Tooltip enter | opacity, transform (scale) | 150ms | ease-out | Tour becomes active or step changes |
| Tooltip exit | opacity | 100ms | ease-in | Tour dismissed (skip/done) |
| Cutout reposition | x, y, width, height (SVG rect) | 200ms | ease | Step changes to new target |
| Scroll to target | scrollIntoView | smooth (browser default) | N/A | Step changes and target is off-screen |

CSS class: `animate-[scaleIn_0.15s_ease-out]` (reuses existing keyframe from globals.css).
