Create `nextjs/components/tour/TourOverlay.tsx` as a client component ('use client' directive).

**Props interface:**
```typescript
interface TourOverlayProps {
  targetRect: DOMRect | null; // null = no target found, show full overlay without cutout
}
```

**Implementation per D-04, D-05, D-06:**

1. Import `createPortal` from 'react-dom'. Use `useState` to track `mounted` state (set true in useEffect to avoid SSR portal issues).

2. Render via `createPortal` to `document.body`.

3. Outer element: `<svg>` with `className="fixed inset-0 w-full h-full pointer-events-none"` and `style={{ zIndex: 100 }}`. The `pointer-events-none` on the SVG prevents click interception. Add a `<rect>` overlay on top with `pointerEvents="all"` to block clicks but NOT dismiss the tour (per D-06).

4. SVG mask approach (per D-05):
   - `<defs><mask id="tour-spotlight-mask">` containing:
     - White rect: `x="0" y="0" width="100%" height="100%" fill="white"` (opaque overlay area)
     - Black rect: position/size from `targetRect` with 8px padding on each side, `rx="8" ry="8"` (transparent cutout), `fill="black"`
   - When `targetRect` is null, omit the black rect (full overlay, no cutout).

5. Main overlay rect: `x="0" y="0" width="100%" height="100%" fill="rgba(0, 0, 0, 0.5)" mask="url(#tour-spotlight-mask)"` with `pointerEvents="all"` (blocks clicks per D-06).

6. Cutout rect transition (per UI-SPEC Animation Contract): Apply CSS transition on the black mask rect's x, y, width, height attributes. Use inline style `transition: 'x 200ms ease, y 200ms ease, width 200ms ease, height 200ms ease'` on the black rect element. Note: SVG rect attributes can be transitioned when set via style or CSS.

   Alternative approach for reliable cross-browser transition: Instead of transitioning SVG attributes directly, use `style={{ x: cutoutX, y: cutoutY, width: cutoutW, height: cutoutH, transition: 'all 200ms ease' }}` on the black rect.

7. Cutout dimensions calculation:
   ```typescript
   const padding = 8;
   const cutoutX = targetRect.x - padding;
   const cutoutY = targetRect.y - padding;
   const cutoutW = targetRect.width + padding * 2;
   const cutoutH = targetRect.height + padding * 2;
   ```

8. Default export. Props destructured in function signature.

**Do NOT:**
- Dismiss the tour on overlay click (D-06 explicitly prohibits this)
- Use CSS box-shadow for the spotlight (anti-pattern per RESEARCH.md)
- Use `width: 100%; height: 100%` on a non-fixed element (Pitfall 3)
