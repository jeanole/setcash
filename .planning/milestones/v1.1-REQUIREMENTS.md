## v1.1 Requirements — All Complete

### Tour Infrastructure
- [x] **INFRA-01**: User's tour completion state is persisted in the database (hasSeenTour boolean)
- [x] **INFRA-02**: User can mark tour as completed via API endpoint
- [x] **INFRA-03**: Tour state is managed through a React context provider
- [x] **INFRA-04**: Tour steps are defined in a centralized configuration with target selectors and content

### Tour UI
- [x] **UI-01**: User sees a speech-bubble tooltip with arrow positioned next to the target element
- [x] **UI-02**: User sees the target element highlighted with a spotlight overlay dimming the background
- [x] **UI-03**: User can navigate the tour with Next, Back, Skip, and Done controls
- [x] **UI-04**: User can navigate and dismiss the tour using keyboard (Esc, arrow keys)

### Integration
- [x] **INTG-01**: Existing UI elements have data-tour attributes for tour targeting
- [x] **INTG-02**: Tour auto-starts on first login for new users and on every login for demo/test users
- [x] **INTG-03**: Tour steps adapt or skip gracefully on viewports below 1024px (corrected from initial 768px assumption)
- [x] **INTG-04**: Tour tooltips and overlay match the current theme (light/dark mode) — verified via CSS variable approach
